# Orden de Servicio - HYGHU & ASOCIADOS

Aplicación web para gestionar órdenes de servicio con integración a Supabase.

## Descripción

Sistema de generación y gestión de órdenes de servicio para HYGHU & ASOCIADOS con almacenamiento en base de datos Supabase.

## Características

- Formulario interactivo de orden de servicio
- Generación de PDF
- Panel de firma digital
- Integración con Supabase
- Diseño responsive

## Tecnologías

- HTML5
- CSS3
- JavaScript
- jsPDF (generación de PDFs)
- Signature Pad (firma digital)
- Supabase (base de datos)

## Configuración

Las credenciales de Supabase están en `config.js`:
- URL: https://trgqcvfhmrkceyguckol.supabase.co
- Anon Key: Configurada en config.js

**Importante**: Nunca expongas la Service Key en el frontend.

## Uso

1. Abre `index.html` en tu navegador
2. Completa el formulario de orden de servicio
3. Firma digitalmente
4. Genera el PDF o guarda en Supabase
